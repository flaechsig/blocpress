🚀 Quick start

  1. Open the Workbench and upload your first ODT template
  2. Validate — the schema is generated automatically from your user-defined fields
  3. Add test data sets and generate a preview PDF
  4. Submit for approval → the template is deployed to the Render API
  5. Generate documents: POST http://localhost:8081/api/render/{name}

🔑 Authentication

This image ships with a built-in dev JWT key. Copy the token from docs/samples/quickstart/token.txt and use it as Bearer token.

Override via -e MP_JWT_VERIFY_PUBLICKEY=… and -e MP_JWT_VERIFY_ISSUER=…
