# TD-0003 — Verschiedene Versionswahl in Workbench und render

Workbench und render wählten unter einem Vorlagennamen verschiedene Versionen (höchste Version gegenüber jüngstem `validFrom`). Seit zu jedem Zeitpunkt höchstens eine Version gilt, wählen beide dieselbe ([Versionierung](../08-concepts/versionierung.md)).

**Folge:** Vorschau und Produktion konnten verschiedene Stände zeigen; heute nur noch bei Altdaten mit Überlappung, die die Workbench beim Start meldet.
