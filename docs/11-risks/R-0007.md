# R-0007 — Bausteine zur Renderzeit über die Workbench

Zeigt ein verknüpfter Abschnitt auf `/api/webdav/released/`, lädt render ihn beim Rendern von der Workbench.

**Folge:** Ist die Workbench nicht erreichbar, scheitert das Rendern in Produktion.

**Maßnahme:** render löst Bausteine nur noch per Name aus der eigenen Datenbank auf ([ADR-0018](../09-decisions/ADR-0018.md)).
