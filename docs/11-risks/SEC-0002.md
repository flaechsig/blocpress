# SEC-0002 — Abhängigkeiten mit bekannten Lücken

Quarkus 3.27.2 zog Netty, Vert.x, pgjdbc und jackson-core mit bekannten Lücken nach (vor allem Denial of Service, Request Smuggling). Zwei Lücken in `quarkus-vertx-http` (CVE-2026-39852, CVE-2026-50559) erlaubten möglicherweise, die pfadbasierte JWT-Prüfung von render zu umgehen; an einer laufenden Instanz nachgewiesen wurde das nicht.
