# SEC-0004 — Container als root

Kein Dockerfile setzte `USER`, die Kubernetes-Manifeste setzten keinen `securityContext`; eine Lücke in einem Dienst führte zu root-Rechten im Container. Das Quickstart-Image bleibt bewusst ausgenommen.
