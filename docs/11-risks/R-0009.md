# R-0009 — Workbench und Import ohne Authentifizierung

Die Workbench prüft kein Token; Freigabe, Ablehnung und Statuswechsel sind für jeden möglich, der sie erreicht. Die Übergabe an render (`/api/render/templates/import`, auch `DELETE`) liegt auf dem öffentlichen Port von render; ohne `BLOCPRESS_AUTH_ENABLED=true` ist sie ohne Authentifizierung.

**Folge:** Unbefugte Freigabe oder Änderung produktiver Vorlagen; wer render erreicht, kann Vorlagen in Produktion am Freigabeprozess vorbei ersetzen oder löschen.

**Maßnahme:** Mit eingeschalteter Absicherung verlangt der Import ein Token mit der Gruppe `reviewer`, das die Workbench vom Benutzer durchreicht ([ADR-0019](../09-decisions/ADR-0019.md)). Offen sind der Import ohne Absicherung und die Workbench ohne eigene Token-Prüfung ([ADR-0017](../09-decisions/ADR-0017.md)).
