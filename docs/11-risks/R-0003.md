# R-0003 — LibreOffice-Version nicht gepinnt

Die Version kommt aus den Paketen von Ubuntu 24.04; ein neues Basis-Image kann Umbruch und Layout ändern. Gleiches gilt für poppler-utils, auf denen der Regressionsvergleich beruht.

**Folge:** Regressionstests schlagen ohne Änderung an der Vorlage fehl; die Ausgabe in Produktion ändert sich unbemerkt.

**Maßnahme:** Regressionstests je Vorlage; Determinismus als Anforderung [REQ-0025](../01-goals/requirements/REQ-0025.md) (vorgeschlagen).
