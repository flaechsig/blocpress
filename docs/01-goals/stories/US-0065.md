Als **Betreiber** möchte ich render ohne Datenbank betreiben, wenn ich nur Vorlagen mit Daten
zu Dokumenten machen will, damit die Installation so klein wie möglich bleibt.

**Warum.** Heute braucht render für jeden Start PostgreSQL, obwohl `/template` sie fachlich
nicht nutzt. Entscheidung [ADR-0016](../../09-decisions/ADR-0016.md): ein Image, Modus zur
Laufzeit über `BLOCPRESS_MODE=engine|full`.
