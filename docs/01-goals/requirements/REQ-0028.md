## REQ-0028 — Schema beim Start migrieren

Beide Dienste führen beim Start ihren Liquibase-Changelog aus
([ADR-0015](../../09-decisions/ADR-0015.md)); danach prüft Hibernate das Schema
(`validate`). Eine leere Datenbank bekommt alle Tabellen; eine Datenbank, die schon die
Tabelle `template` hat, behält Tabellen und Daten, das erste Changeset wird nur vermerkt.

Bewiesen durch `LiquibaseMigrationTest` in render und workbench mit
`@DisplayName("REQ-0028: …")`, gegen PostgreSQL 18: leere Datenbank migriert und von
Hibernate akzeptiert; mit Hibernate angelegte Datenbank samt Datensatz übernommen
(`MARK_RAN`), Datensatz erhalten, Prüfung bestanden. Eine Gegenprobe zeigt, dass die Prüfung
ein fehlendes Schema erkennt.
