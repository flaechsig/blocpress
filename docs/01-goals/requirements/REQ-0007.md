## REQ-0007 — Kein stiller Rückfall auf das en-Format

Geprüft wird beim Start des Render-Service (`RenderLocaleConfig`, `@Startup`) gegen
die zur Laufzeit verfügbaren Locales (`LocaleSupport`). Für Sprachen, die eine
*Vorlage* verlangt (REQ-0005), ist ein Startabbruch nicht möglich — dort wird
einmalig je Sprache gewarnt.

Bewiesen durch `RenderLocaleConfigTest` (`@DisplayName("REQ-0007: …")`): ungültige/leere Tags
und Sprachen ohne Sprachdaten (`xx-XX`) werden mit Meldung abgelehnt. **Teilbeleg:**
Der Test prüft die Validierung; dass der Start dadurch abbricht (`@Startup`), wurde
für 2.5.1 manuell im Native-Image nachgewiesen (`xx-XX` und, im Image mit fester
Locale-Liste, `fr-FR` → Exit-Code 1), ist aber nicht automatisiert getestet.
