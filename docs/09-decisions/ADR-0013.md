---
id: ADR-0013
title: REST-API von render API-first aus openapi.yml
status: proposed
date: 2026-10-05
---

## Kontext

render hat eine API-Beschreibung (`blocpress-render/src/main/resources/META-INF/openapi.yml`),
aus der der OpenAPI-Generator beim Bauen Interfaces und Datenklassen erzeugt. Benutzt
werden nur die Datenklassen. `RenderResource` implementiert das erzeugte Interface seit
März 2026 nicht mehr (Commit ad50a43): `/api/render/template` nimmt Multipart und JSON an,
der Generator macht daraus eine einzige Methode, die nur die Multipart-Felder kennt. Die
JSON-Variante ließ sich damit nicht abbilden.

Seitdem prüft niemand, ob Beschreibung und Code zusammenpassen. `openapi.yml` beschreibt
außerdem nur 2 von 7 Endpunkten; Jobs, Job-Ergebnis, Import und Dashboard fehlen.

## Entscheidung

Die REST-API von render ist **API-first**: `openapi.yml` ist die einzige Quelle. Jede
Ressource implementiert das erzeugte Interface, sodass der Build bricht, wenn Code und
Beschreibung auseinanderlaufen. Eine Änderung an der API beginnt in `openapi.yml`.

- Beide Varianten zum Rendern mit mitgeschickter Vorlage bleiben, auf getrennten Pfaden:
  `POST /api/render/template` für Multipart (so stehen sie in den Anleitungen der Website)
  und `POST /api/render/template/json` für JSON.
- `openapi.yml` beschreibt alle Endpunkte von render, auch Jobs, Import und Dashboard.
- Der Generator erzeugt keine Swagger-Annotationen mehr (`useSwaggerAnnotations=false`);
  die Abhängigkeit `swagger-annotations` entfällt.

Verworfen:
- **Nur die Datenklassen erzeugen:** kleinste Änderung, aber der Abgleich zwischen
  Beschreibung und Code fehlt weiter.
- **Code-first** (Beschreibung aus den Annotationen im Code erzeugen): eine Quelle, aber
  die API entsteht beim Bauen statt vorher beschrieben zu werden.

## Konsequenzen

- Bruch der API: JSON-Aufrufe von `/api/render/template` ziehen auf
  `/api/render/template/json` um (e2e- und Lasttests). Es gibt keine bekannten fremden
  Nutzer.
- Jede API-Änderung betrifft zwei Dateien, `openapi.yml` und die Ressource.
- Die Beschreibung, die Quarkus ausliefert, ist vollständig und stimmt mit dem Code überein.
