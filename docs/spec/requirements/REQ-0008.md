## REQ-0008 — Optionale JWT-Absicherung der Render-API

Geschützt bei eingeschaltetem JWT: `/api/render/template`, `/api/render/{name}`,
`/api/render/jobs…`, `/api/render/dashboard…`. Bewusst offen: der interne Import
`/api/render/templates/import…` und `/q/…`. Nur Authentifizierung, keine
Rollenprüfung (RBAC → US-0021). Entscheidung: [ADR-002](../../architecture/decisions/ADR-002.adoc).

Bewiesen durch `RenderAuthEnabledTest` und `RenderAuthDisabledTest` (`@QuarkusTest`,
`@Tag("REQ-0008")`): eingeschaltet → ohne bzw. mit gefälschtem Token 401, mit gültigem
Token 200 (Rendern, `{name}`, Jobs, Dashboard); Import und `/q/health` bleiben offen.
Ausgeschaltet → 200 ohne Token und auch mit fremdem Token. Zusätzlich manuell geprüft,
dass `BLOCPRESS_AUTH_ENABLED` am gepackten Programm zur Laufzeit wirkt (2026-10-02).
