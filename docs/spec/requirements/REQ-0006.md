## REQ-0006 — Einstellbare Ersatzsprache

Die Ersatzsprache wird explizit durchgereicht (`RenderEngine.mergeTemplate(URL,
JsonNode, Locale)`); die zweistellige Variante verwendet `de-DE`. Der Render-Service
setzt sie aus `blocpress.render.default-locale` (BCP-47-Tag).

Bewiesen durch `DefaultLocaleTest` (`@Tag("REQ-0006")`): Styles ohne Sprache folgen
der Ersatzsprache (de-DE → `500.000`/`83,00`, en-US → `500,000`/`83.00`), auch bei
gegenläufig gesetzter JVM-Standardsprache; `RenderLocaleConfigTest#factoryExposesValidatedLocale`
deckt die Übernahme aus der Konfiguration ab.
